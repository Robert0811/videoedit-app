VideoEdit — Privacy Policy

Last updated: November 16, 2026

Summary

VideoEdit is a personal tool that runs on its owner's computer. It does not collect, sell or share personal data, and it has no servers of its own.

Data the tool accesses

When the owner connects a YouTube channel, VideoEdit receives permission from Google to upload and manage videos on that channel. With this permission it can:

  • upload video files chosen by the owner;
  • set or change the title, description, tags, thumbnail, visibility and scheduled publication date of those videos;
  • read basic information about the channel and its list of videos, to confirm the correct channel is connected.

How the data is used

The access is used only to perform the actions above, at the owner's request. Data obtained through Google APIs is not used for advertising, is not transferred to third parties, and is not used to train AI or machine-learning models.

Where the data is stored

The access credentials issued by Google are stored only in a local file on the owner's computer. Nothing is sent to any server other than Google's own APIs.

Revoking access

Access can be removed at any time from the Google Account page at myaccount.google.com/permissions, or by deleting the local credentials file.

Google API Services User Data Policy

VideoEdit's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be raised through the issues page of the project repository where this page is hosted.
